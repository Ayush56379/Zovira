# NovaCart — Frontend Phase 1: Home

This is the first frontend module of the marketplace.

## Files
- index.html
- style.css
- script.js

## Run
Open `index.html` directly in a browser or use VS Code Live Server.

## Current functionality
- Responsive premium white UI
- Mobile menu
- Search panel and suggestions
- Category filtering
- Product filtering
- Wishlist stored in localStorage
- Cart stored in localStorage
- Cart drawer
- Wishlist drawer
- Flash-sale countdown
- Newsletter UI
- Scroll reveal animations
- Working homepage interactions

## Important
Authentication, real database, Cashfree payments, seller applications, shipping, wallet and 15-day settlement are intentionally not mocked here. They will be connected in later modules without rebuilding this homepage architecture.
